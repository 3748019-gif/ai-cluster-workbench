# 隐私与发布边界

本次按公开发布标准准备源文件，用户已明确授权以独立的Public仓库发布。MIT许可证已按用户授权加入；邀请协作者或新增外部集成仍需维护者另行决定。历史本地审阅材料不随仓库上传。

仓库仅收录代码、模板、使用说明和测试样本。不收录真实任务数据库、交换文件、个人知识库、学校业务文件、账号观察、额度记录、会话截图、历史运行日志或原始证据包。原v2.4包中的verification目录整体保留在维护者本地。

一个Word失败回放样本包含个人文档属性，发布衍生版仅清除docProps/core.xml中的作者、最后修改者及时间字段。正文、表格、样式和其他ZIP成员逐项保持原字节。provenance登记变换及原、新哈希；不冒充原始文件完全相同，也不修复故障样本。

测试代码中的/Users/private/source.json是用于验证路径泄漏检测的虚构字符串；工程课程样本为合成数据。成员名、模型名和默认策略是可配置示例，不表示账号已登录、模型仍可用或权限已经授予。

本次检查覆盖文本、嵌套DOCX XML、常见密钥与凭据模式、个人路径、文件类型和逐文件清单。扫描无命中不能保证不存在所有形式的秘密；实际扫描结果及限制见验证结果。没有上传本地审计原文或原包。

仓库未配置GitHub Actions、Pages、自动发布、外部Webhook或遥测，也不新增依赖。以后新增文件仍需逐项检查，.gitignore不能阻止主动上传被忽略文件。

原始冻结ZIP和本地审阅材料不在本仓库中。项目代码与随附文档适用MIT；外部客户端、模型服务及另行提供的业务资料不因此获得许可。上传后核实项目名称、内容完整性及GitHub的Public标识，不把拟定设置当成已经发布成功的证据。
